## Why these standards matter

| Standard | Review relevance |
| --- | --- |
| OWASP Top 10 | Prioritises exploitable application weaknesses such as injection, XSS, SSRF, and insecure software supply chain issues. |
| OWASP ASVS | Provides verification depth for secure code review, dependency hygiene, auth, logging, and crypto checks. |
| CWE/SANS Top 25 | Supplies weakness IDs and remediation context for findings. |
| NIST SP 800-53 | Supports auditable change, assessment, vulnerability, and remediation controls. |
| ISO/IEC 27001:2022 | Reinforces secure development lifecycle evidence and vulnerability handling. |
| PCI-DSS v4.0 | Raises the bar for secret handling, secure coding, and remediation cadence in payment-related systems. |
| DORA | Adds resilience and traceability expectations for high-risk production changes. |
| Semgrep registry | Useful optional local or CI enrichment for multi-language static analysis. |
