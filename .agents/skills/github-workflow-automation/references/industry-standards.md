# Industry standards and good practice

- DORA metrics recommend fast feedback loops, safe rollouts, and quick recovery; this skill separates CI, CD, and post-deploy validation to support that model.
- ITIL and SRE guidance both emphasize rollback readiness, deployment evidence, and production approval gates.
- SLSA and OpenSSF guidance emphasize provenance, immutable dependencies, and hardened build systems.
- GitHub recommends least-privilege `permissions:`, pinned third-party actions, and secure secret handling.
- OWASP CI/CD security guidance recommends scanning source, dependencies, and images; validating branch protections; and avoiding hard-coded credentials.
