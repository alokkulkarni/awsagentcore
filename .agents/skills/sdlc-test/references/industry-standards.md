# SDLC Test Industry Standards

## Core References

- **IEEE 829** — legacy but widely recognised test documentation structure
- **ISTQB Foundation Level** — https://www.istqb.org/
- **Kent Beck / TDD** — *Test Driven Development: By Example*
- **BDD / Cucumber** — https://cucumber.io/docs/bdd/
- **Google Testing Blog** — https://testing.googleblog.com/
- **agentskills.io** — https://agentskills.io

## Recommended Coverage Targets

- **Line coverage:** 80% or higher
- **Branch coverage:** 70% or higher
- **Critical paths:** prefer explicit unit + integration + E2E coverage

## Why these standards matter

| Standard | Test-phase relevance |
| --- | --- |
| IEEE 829 | Supplies a disciplined test-plan and test-case structure. |
| ISTQB | Encourages sound test-design techniques and coverage reasoning. |
| TDD | Promotes incremental, behaviour-focused test creation close to implementation. |
| BDD | Improves user-journey and acceptance-test clarity. |
| Google Testing guidance | Reinforces maintainable, layered, trustworthy test suites. |
