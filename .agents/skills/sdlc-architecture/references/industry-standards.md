# Industry Standards and External References

This skill aligns to the following external references and should use them when explaining architecture decisions and validation rules.

- **TOGAF ADM** — enterprise architecture method for developing, governing, and iterating architecture artefacts.  
  URL: https://www.opengroup.org/togaf
- **C4 Model (Simon Brown)** — architecture communication model focused on context, containers, components, and code.  
  URL: https://c4model.com/
- **ISO/IEC/IEEE 42010** — architecture description standard covering stakeholders, concerns, viewpoints, and rationale.  
  URL: https://www.iso.org/standard/50508.html
- **arc42** — pragmatic software architecture documentation template.  
  URL: https://arc42.org/
- **NIST Secure Software Development Framework (SSDF)** — security-aware architecture and engineering reference.  
  URL: https://csrc.nist.gov/Projects/ssdf
- **agentskills.io** — production patterns for skill packaging, validation, references, and templates.  
  URL: https://agentskills.io
