# Amazon Connect Chat Test Suite

Automated chat testing for Amazon Connect contact flows backed by a Lex bot.
Generated by [amazon-connect-chat-tester](https://github.com/your-org/amazon-connect-chat-tester).

## Quick start

```bash
# Install Python dependencies
pip install -r requirements.txt

# Copy and fill in credentials
cp .env.example .env
# edit .env with your values

# Run all scenarios locally
pytest test_connect_chat.py -v

# Run a single scenario
pytest -k BANK-101 -v

# Open the HTML report
open reports/chat_test_report.html
```

## Configuration

| Variable | Description |
|----------|-------------|
| `AWS_REGION` | AWS region (eu-west-2) |
| `CONNECT_INSTANCE_ID` | Amazon Connect instance UUID |
| `CONNECT_CONTACT_FLOW_ID` | Default contact flow ARN |
| `CHAT_TIMEOUT_SECONDS` | Per-turn bot response timeout |
| `CHAT_DURATION_MINUTES` | Max chat session duration |

## Zephyr Squad Integration

Zephyr integration is currently **disabled**. To enable it:

1. Set `ZEPHYR_ENABLED=true` in your `.env` (local) and as a GitHub variable.
2. Add Jira credentials to `.env` and as GitHub secrets (see `.env.example`).
3. Re-run `./setup-github.sh` to push the new values.

## Adding test scenarios

Create a `.yaml` file in `scenarios/` (see `scenarios/sample_scenarios.yaml`
for the schema). Multi-document files (separated by `---`) are supported.

```yaml
zephyr_issue_key: "BANK-105"
name: "Verify loan enquiry intent"
turns:
  - send: "I want to apply for a loan"
    expect_contains: "loan"
    timeout_seconds: 12
  - send: "Personal loan please"
    expect_contains:
      - "amount"
      - "term"
```

## GitHub Actions

The workflow at `.github/workflows/connect_chat_zephyr_suite.yml` runs on:
- Push to `main` (when scenario or Python files change)
- Pull requests to `main`
- Manual dispatch with optional `scenario_filter`, `dry_run`, and `skip_zephyr` inputs

## IAM permissions required

The OIDC role needs these Amazon Connect permissions:

```json
{
  "Effect": "Allow",
  "Action": [
    "connect:StartChatContact",
    "connect:StopContact",
    "connectparticipant:CreateParticipantConnection",
    "connectparticipant:SendMessage",
    "connectparticipant:GetTranscript",
    "connectparticipant:DisconnectParticipant"
  ],
  "Resource": [
    "arn:aws:connect:eu-west-2:ACCOUNT_ID:instance/f969d4b4-f716-4974-a325-bb7899f2f293",
    "arn:aws:connect:eu-west-2:ACCOUNT_ID:instance/f969d4b4-f716-4974-a325-bb7899f2f293/*"
  ]
}
```
